# Prompts — step 02: project structure (React Native)

| Task | Instruction |
|---|---|
| Project | "Generate the bare project with the official React Native CLI at the current version. Move the app into `src/app`." |
| Versions | "Before adding a plugin, check its peer dependencies against what the template ships." |
| Guards | "Enforce the layers with ESLint boundaries. React Native is a package, not a layer: close that gap too. Add the casing rule." |
| Proof | "Break each rule on purpose, capture the errors for the guide, remove the violations." |
| CI | "Fast checks first, then the Android and iOS builds. Reuse the iOS repo's annotation script." |
